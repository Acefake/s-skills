## 运行环境适配

在 Codex 或 T3 Code 中，执行前先阅读[宿主适配规则](../../../plugins/s/HOSTS.md)；其中的模型、委派、浏览器和定时任务规则优先于下文的 Cursor 专用示例。


把你上一条消息重新说一遍。别再用行话，说得连贯一点。说得更简单、更简短，就像一个人跟另一个人说话那样。
