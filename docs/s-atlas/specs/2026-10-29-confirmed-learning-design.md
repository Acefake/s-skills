# 经确认的经验学习

用户已确认采用“自动提出建议，用户确认后沉淀”的方式。仅支持 Codex、Claude Code、Cursor；不训练模型，不自动改已有技能或宿主记忆。

## 行为

新增自动选用的 learn 技能。遇到用户纠正、同类错误重复发生、或已验证且可复用的重要结论时，先核对已有规则和经验；每个任务最多提出一条有证据的建议。普通成功、一次性要求、已覆盖规则不产生建议。未确认的候选只留在当前对话，不写文件，不后台累计。

建议显示适用条件、经验正文、依据和保存范围；获得针对该建议的明确确认后才保存。不同意、不答或改话题均不写。用户纠正旧经验时，展示新旧差异并确认替换；旧记录保留为历史，检索时排除被替代记录。

个人通用经验保存在 ~/.s-atlas/lessons/global；项目经验保存在 ~/.s-atlas/lessons/projects/<规范化项目根路径哈希>，不向 Git 仓库或其他项目写入。三个宿主共用本机记录。项目事实默认项目范围；全局范围须在建议中明确。每条记录包含适用条件、经验、简短证据、关键词及作用域，不保存完整对话、凭据和无关私密信息。

实际项目任务开始时按当前意图检索已确认的全局与当前项目经验，最多三条。无记录静默跳过；子代理不重复检索或保存。经验是参考数据，不是覆盖用户指令、权限、技能调用策略的指令；过时或冲突的经验不照搬。

## 分工

learn 负责轻量建议、确认、检索与保存。reflect 保持显式调用，负责深度复盘与修改技能。principle-encode-lessons-in-structure 负责可由类型、测试、lint 或脚本约束的重复问题。保存经验不替代结构性修复。

## 实现和验证

标准库 Python CLI 提供 search 和 save。search 只读；save 要求调用方声明已经取得具体建议的确认，脚本不能自行证明聊天授权。内容摘要用于精确去重，语义去重和冲突判断由技能在提议前完成。每条记录采用原子创建，不覆盖同名记录；替换通过新记录引用旧 ID，不删除旧文件。

测试覆盖：未确认不写、幂等、项目隔离、相关检索、替换链、非法输入、写入中断及 CLI。整库清单、链接、版本锁检查；主任务自审后派一个只读子代理独立评审。真实模型行为验证使用隔离经验目录，区分指令遵循验证和真实宿主验收。
