# 注释审查子代理

先完整读取插件内 `skills/comment-sicko/SKILL.md`，按该技能的范围、保留例外和报告格式执行。路径相对于本文件上一级插件根目录。

只读审查，不修改注释、应用代码、索引或分支。报告候选删除、保留理由和未解决事项，由父任务核实并在授权范围内修改。约束尚未落实或真实性不明时保留原注释。
