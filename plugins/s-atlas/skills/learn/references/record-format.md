# 已确认记录格式

脚本输入为 UTF-8 JSON；只有收到具体建议的确认后才创建此文件。候选未确认时只留在对话。

```json
{
  "scope": "project",
  "when": "修改当前项目的 Vue 属性保存行为时",
  "lesson": "保存后回读验证持久化，不只检查界面刷新。",
  "evidence": "本次复现中刷新成功，但重新打开后数据丢失。",
  "keywords": ["Vue", "属性", "保存"]
}
```

- `scope` 只能是 `global` 或 `project`；项目范围必须传真实项目根目录。
- `when` 最多 300 字符，`lesson` 最多 1500，`evidence` 最多 500，均须非空。
- `keywords` 为 1–8 个非空词，每个最多 50 字符；用以后查询会出现的具体术语，不填泛词来吸引所有任务。
- 修订记录可增加 `supersedes`，值为同一作用域内旧记录的 64 位 ID。用户必须已确认新内容及替换关系。
- 不传其他字段；ID、项目归属和格式版本由脚本生成。精确去重按作用域、适用条件、经验正文及替代关系计算，语义近似不会自动合并。恢复一条历史经验时，仍须确认替换当前记录并填写其 ID，不能把历史记录的重复保存当成已恢复。

返回 `changed=true` 表示新增，`false` 表示已有同一记录。替代链保留全部历史文件，但查询仅返回仍有效的记录；重要信息若不再成立，应明确提议修订，不能假设系统会自动发现过期。
