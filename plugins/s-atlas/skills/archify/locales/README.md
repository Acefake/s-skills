# 内置查看器语言目录

`manifest.json` 登记了 `meta.locale` 会自动选用的语言目录。
渲染器只读取其中列出的文件，路径相对于此安装
目录。它绝不会扫描此目录、工作目录或任何其他
位置来查找语言文件。

`en.json` 是规范消息集和最终回退。每个其他
目录都按键逐一对照它进行校验：缺失、未知或
占位符不匹配的条目回退为英文，并在渲染该
语言时报告。因此新的 UI 键可以先只提供英文。

每条消息的解析顺序为：有效的 `meta.translations` 值 → 选定的内置
目录 → 英文。见 [the authoring contract](../references/authoring-contract.md)。

要登记一种语言，在此添加其完整目录，并添加一条 manifest 条目。
无需修改渲染器或 schema。语言标签匹配不区分大小写；
地区和书写系统变体（例如 `zh-Hant`）是不同的标签，
绝不会合并到另一个目录上。

完整性检查只证明键和占位符的覆盖，不证明母语措辞、
复数语法、从右到左布局或字形覆盖。

阿拉伯语目录只本地化文案。阅读器文字/界面方向和场景
几何保持不变；完整的 RTL 支持在 [#935](https://github.com/tt-a1i/archify/issues/935) 中跟踪。
路由/可达范围导出摘要和可达范围控件在现有 `.one`/`.other` 模型内
使用与数量无关的标签。其他计数消息仍受该
模型在阿拉伯语复数方面的限制。

其他可复用、未登记的示例位于 `../examples/locales/`；通过
`meta.translations` 提供它们。
