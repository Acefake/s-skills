# 守住上下文窗口

大输出、长文件和计划应按阶段读取，主对话保留决定和证据入口，避免上下文溢出或压缩时丢失关键事实。

## 做法

1. **限制当前阶段。** 先定本轮要回答的问题、文件数量和范围，把阶段轮次上限写进计划或续读记录。估计输出是否装得下，把工具和编排本身的开销算进去；达到预算时先保存进度，再安排下一阶段。
2. **先定位再读取。** 用路径、标题或搜索结果找相关范围；需要完整阅读的文件按行段或章节分批，不一次倾倒全部内容。
3. **处理截断。** 发现输出截断就记录最后确认的位置，以更小范围补读。命令成功或读文件脚本执行完，不代表模型已经看完内容。
4. **外置长资料。** 原始输出、完整计划和中间记录保存在任务工作目录，主对话引用路径、范围和摘要；摘要区分已验证事实、推断和未知项。
5. **维护续读点。** 阶段结束记录目标、已完成项、关键决定、证据位置和下一步，恢复时先核对当前状态，不从头重做。
6. **需要委派时带证据回传。** 只有已获授权且宿主支持时，才将独立阅读任务分出去；返回摘要、文件位置和未覆盖部分，不将整段输出搬回主对话。

## 完成标准

续读记录包含阶段预算、已用轮次、原始证据和未完成范围。另一次继续执行能据此恢复；没有读到的内容保持“未读”，不以摘要代替必须完成的全文检查。
