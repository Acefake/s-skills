# 初始化时的交互提问

`wukong-init`、`setup-s-instructions` 和 `setup-s-models` 共用以下规则。宿主对工具用途和模式的限制优先，不为弹出选项擅自切换模式。

1. 检查当前会话实际提供的提问工具。Codex / T3 普通模式提供 `request_user_input_async` 时，优先用它显示选项；不能因为 `request_user_input` 仅限 Plan 模式，就认定普通模式没有提问工具。
2. 没有异步工具时，用当前模式允许的同步提问工具，例如 `request_user_input` 或 Claude Code 的 `AskUserQuestion`。工具未提供、当前模式不允许、或调用明确报错时，才退回编号文字提问，并说明退回原因。不虚构工具，不反复调用已被拒绝的工具。
3. 一次只问当前这一步。工具限制选项数量时，拆成连续的问题，保留所有原有选择；自定义模型、修改某行等输入允许使用自由文本。不要为凑选项数量删掉预算档位。
4. 异步调用返回只表示问题已展示，不表示用户已回答。停止依赖答案的步骤，等待用户明确回复；不轮询、重复提问，也不把超时、预选项、沉默或其他任务消息当作答案。
5. 选择宿主、选择预算、接受完整角色预览、确认写入仍是独立步骤。先展示完整差异或标记段，再单独请求写入确认；接受预览不授权写入。只有工具允许用于写入确认时才用它，否则用文字单独确认，等待明确答复。此规则不改变两个设置技能原有的跳过、拒绝和中断处理。
