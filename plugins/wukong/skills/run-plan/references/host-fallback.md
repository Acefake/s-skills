## 宿主适配

T3 Code 按 [T3 编排参考](../../wukong-router/references/t3-code-tools.md) 报告工具、提供商、模型或隔离失败，不擅自切换原生工具、CLI、权限或隔离方式。返回 `next` 要求等待唤醒时结束回合，不轮询。

具体派发工具和参数见[宿主适配](../../../HOSTS.md)。用户指定的模型不可用时报告，不自行换模型；不能派子代理时由主线程按顺序执行，不声称已并行或具有独立评审。

### 通用回退

找不到工具或类型时，按[宿主适配](../../../HOSTS.md)选择不改变任务边界的可用能力并说明。不声称未发生的检测或执行。不能派子代理时由主对话顺序完成并自行审查，明确缺少独立审查。
