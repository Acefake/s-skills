# 穷尽设计空间

没有先例、无法仅凭现有约定决定的交互或架构，先用少量竞争原型取得证据，再选方案。产品“手感”需要实际体验，不能只比较文字描述。

## 做法

1. **固定比较条件。** 写清目标、不可违反的约束、代表性输入和使用场景，确定怎样判断适合。
2. **提出 2–3 个不同方案。** 区分结构或交互上的真实取舍，不用同一方案换配色、换名称充数。
3. **做最小原型。** 每个只实现足够暴露关键取舍的路径，使用同一输入；不提前做生产级完善。
4. **同条件比较。** 实际运行或体验，记录观察结果、未覆盖条件和实现代价。涉及测量时区分实测与推断。
5. **收敛。** 说明选哪个、为何淘汰其他方案、还存在哪些限制。证据不足就补能区分方案的实验，不把偏好写成已证明的结论。

## 完成标准

留下一份能定位原型和比较证据的选择记录。已有明确先例或用户已确定方案时，不为了凑数量重新探索。
