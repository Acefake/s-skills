# Viewer Runtime 参考

只有当用户要求某项面向读者的能力时才阅读本文。普通生成不需要实现或重新记录这些功能；它们已经在生成的 HTML 中。

## 探索

- Diagram Guide 列出当前的操作和快捷键。用 guide 按钮或 `?` 打开它；它绝不会自动打开。
- Reading Depth 在默认 100% 缩放时从 READ 开始，在 175% 时显示 FULL 细节，只有低于 100% 时才回落到 MAP。聚焦、路由和语义交互在任何缩放下都会显示其确切事实。
- Semantic Lens 汇总选定的节点/关系种类，不改变编写的几何。
- Intent Trace 在确认聚焦之前预览精细指针或键盘目标。
- Node Finder 搜索标签和稳定 ID。
- Semantic Passport 在聚焦时打开，显示编写的上游/下游事实，支持可复制的深链接，有明确的关闭操作，在真正的外部激活和 Escape 时关闭，并且绝不进入规范导出。
- Semantic Radar 镜像可见视口和编写的图，而不会成为第二个事实来源。
- Direct Relationship Pin 让一条唯一的已编译关系可操作，同时保留编写的线条和稳定的关系身份。在来源/目标/标签/ID 元数据冲突时，它必须以失败关闭。
- Route Probe 在编写的有向关系上解析恰好两个端点。它绝不从几何推断路由。

## 嵌入式阅读地址

在不透明 `srcdoc` 框架中显示原生阅读器的宿主，可以在该阅读器的 `html` 元素上设置 `data-reading-link-template`。提供一个绝对的 HTTP、HTTPS 或 file URL，其中恰好包含一个 `{state}` 标记，例如 `https://example.test/architecture#page=mechanism&reader={state}`。原生的 Focus、Relationship、Reach、Route 和 Lens 复制操作会把该标记替换为它们经百分号编码的不透明查询状态。宿主保持其页面身份，并把该值恢复为原生框架的 hash；它绝不解析或重建查询。

未配置时保留独立链接。无效的、携带凭据的或不受支持的 URL 模板会使复制失败，且不会访问剪贴板。这个接缝只改变复制出的地址，不改变查询解析、历史、权限、嵌入隔离或编写的几何。它不增加任何网络或存储面。

## 动效与演示

每张渲染出的图默认启用由读者控制的 Live/Still 动效。在 Live 下，每条连线在同一个共享周期上运行一个小型灯光秀：一颗彗星（光晕、光环、尾巴、头部，外加每条连线上一个较暗的回声）向下游级联，留下柔和的尾迹，并在目标节点上落成一圈涟漪；节点则入场一次，然后按编写的步骤错开，在同一周期上发光。各阶段遵循编写的步骤顺序（来源节点的排序，在时序图中按时间顺序）；流动效果运行在单独的查看器覆盖层上，原有的线条样式和箭头保持不变。紧凑连线会得到更大、更亮的彗星；回声保持较暗。没有已保存偏好时，新页面以 Still 开始。选择 Live 会开始持续流动并保存该偏好；选择 Still 会停止它并清除已保存的 Live 偏好。已保存的 Still 偏好保持 Still。语义探索会临时占用动效预算，当该操作释放它时持续流动恢复。没有连接的图保留其有界的节点入场，而不是凭空制造流动。省略 `meta.animation`；历史上的 `"trace"` 和 `"none"` 值仍为输入兼容而被接受，且不改变这一默认行为。减少动效、页面隐藏、打印和规范导出都保留完整的静态含义。Presentation Stage 改变查看器外框和取景，绝不改变编写的几何。这不是移动端产品功能；窄布局只获得容纳适配。

## 规范导出

导出菜单可以复制/下载整图 PNG、下载 JPEG/WebP、下载双主题 SVG，以及录制启用追踪的 WebM。查看器状态——Guide、Lens、finder、聚焦、路由、相机、雷达、演示、动效占用和临时覆盖层——必须从规范导出中移除。

打开、关闭或完成一次导出，都会保留当前的 Focus/Reach 选择，以便继续探索。由导出发起的下载激活不算外部关闭；真正的外部激活和 Escape 保持其原有行为。整图 PNG/SVG 导出仍包含完整的规范图，而 Reach Share Card 传达的是当前编写的闭包。

### Route Share Card

在一次真实的有向 Route Probe 解析之后，读者可以使用 **Export → Route Share Card**。它复用确切的有序路由快照和共享的 Share Card 接缝：`format=share-card`、`variant=route`。隔离的克隆只能使用静态的 `data-share-route-*` 装饰。它只能下载，对过时/不可达/冲突的路由以失败关闭，并且绝不会成为规范产物。

### Reach Share Card

在一次非空的编写可达性查询之后，读者可以使用 **Export → Reach Share Card**。它直接使用已经解析出的上游/下游节点和连线集合，不重新执行遍历：`format=share-card`、`variant=reach`。隔离的克隆只能使用静态的 `data-share-reach-*` 装饰。它只能下载。称它为编写的可达性——而不是影响、爆炸半径、破坏或运行时因果。

## 真实性边界

查看器导出是沟通用素材。它们不能代替经过检查的 HTML、确定性的交付回执或真实的视觉审查。不要为这些仅限查看器的能力增加托管服务、存储面、依赖、schema 分支或移动端产品面。
