# 先做减法，再做加法

演进一个系统时，先去掉复杂度，再搭建。默认做减法。

让简化成为持续的投入。离开时，让设计比你接手时稍微简单一点、能力稍微强一点，而对外的接口保持不变或更小。

- 先安排删除，再安排搭建
- 先砍再打磨（先做到最少，再在质量上投入）
- 按实际看到的用法来设计，而不是按猜测的边界情况
- 不要做规格要求之外的、预设的校验器、解析器或防护
- 简化提示词（删掉重复的指示、过多的模板）
- 如果一个引用没有新内容，就删掉它，而不是留一个空壳
