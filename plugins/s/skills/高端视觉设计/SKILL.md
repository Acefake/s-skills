# 高端视觉设计

按一家能做出奖项级界面的主设计师来做，同时负责动效编排。交付的是有触感、有空间节奏、交互细、动作顺的数字体验。不要连续两次交出同一套版式或同一套审美。按提示的语境，从下面的高级版式和质感里挑一种组合，同时守住苹果式、Linear 这一档的设计语言。

## 绝对不要出现的东西

生成的代码里只要出现下面任何一条，这份设计就失败：

- **禁用字体：** Inter、Roboto、Arial、Open Sans、Helvetica。默认可以用 `Geist`、`Clash Display`、`PP Editorial New`、`Plus Jakarta Sans` 这一类。
- **禁用图标：** 笔画很粗的常规 Lucide、FontAwesome、Material Icons。只用极细、准确的线，例如 Phosphor Light、Remix Line。
- **禁用边框和阴影：** 普通的 1px 实线灰边。又黑又硬的投影（`shadow-md`、`rgba(0,0,0,0.3)`）。
- **禁用版式：** 贴着屏幕上沿、左右拉满的吸顶导航。对称、无聊、没有大留白的三列 Bootstrap 式格子。
- **禁用动效：** 标准的 `linear` 或 `ease-in-out`。状态瞬间切换、中间没有插值。

## 动手前先选定一种组合

写代码前，按提示的语境从下面各挑一个。组合要贴题，同时保持高级。

### 气质和质感（选 1）

1. **空灵玻璃（软件服务 / AI / 科技）：** 最深的 OLED 黑（`#050505`），背景里很淡的径向网格渐变（例如微微发光的紫或翠绿光斑）。接近纯黑的卡片，用很重的 `backdrop-blur-2xl`，以及纯白 10% 的发丝线。宽的几何无衬线标题。
2. **编辑式奢华（生活方式 / 地产 / 机构）：** 暖奶油（`#FDFBF7`）、Muted sage（灰绿），或深浓缩咖啡色。大标题用高对比的可变衬线。叠一层很淡的 CSS 噪点或胶片颗粒（`opacity-[0.03]`），让它有纸的感觉。
3. **柔软的结构（消费 / 健康 / 作品集）：** 银灰或纯白背景。很大、很粗的无衬线标题。组件像浮着，阴影极软、散得很开。

### 版式（选 1）

1. **不对称便当盒：** 像砌体一样的 CSS Grid，卡片大小不一（例如 `col-span-8 row-span-2` 旁边叠两张 `col-span-4`），打破单调。
   - **手机：** 收成一列（`grid-cols-1`），竖向间距宽（`gap-6`）。所有 `col-span` 回到 `col-span-1`。
2. **纵深叠卡：** 元素像实体卡片叠在一起，彼此略微重叠，景深不同，有的轻轻转 `-2deg` 或 `3deg`，打破数字网格。
   - **手机：** `768px` 以下去掉旋转和负外边距的重叠，竖向按正常间距排。重叠会让触摸目标打架。
3. **编辑式对半：** 左半（`w-1/2`）是很大的字，右边是可交互、可横向滚动的图片胶囊，或错落的可交互卡片。
   - **手机：** 变成通栏竖排（`w-full`）。字在上，可交互内容在下。需要的话保留横向滚动。

**手机上的统一规则：** 上面这些不对称版式，在 `md:` 以上才展开。视口窄于 `768px` 时，必须回到 `w-full`、`px-4`、`py-8`。通高的区块不要用 `h-screen`，用 `min-h-[100dvh]`，避免 iOS Safari 视口跳动。

## 组件要有触感

### 双层边框（Doppelrand，嵌套的外壳）

高级卡片、图片、容器不要平贴在背景上。要像一块玻璃板放在铝托盘里：外面一层壳，里面一层芯。

- **外壳：** 包一层 `div`。背景很淡（`bg-black/5` 或 `bg-white/5`），外圈发丝线（`ring-1 ring-black/5` 或 `border border-white/10`），有明确的内边距（例如 `p-1.5` 或 `p-2`），外圆角大（`rounded-[2rem]`）。
- **内芯：** 真正放内容的那一层。自己的背景色，自己的内高光（`shadow-[inset_0_1px_1px_rgba(255,255,255,0.15)]`），圆角按同心圆算小一圈（例如 `rounded-[calc(2rem-0.375rem)]`）。

### 按钮里再套一个按钮

- **结构：** 主要按钮是完全圆的胶囊（`rounded-full`），内边距宽（`px-6 py-3`）。
- **尾部图标：** 按钮上如果有箭头（`↗`），不要光秃秃贴在文字旁边。放进它自己的圆（例如 `w-8 h-8 rounded-full bg-black/5 dark:bg-white/10 flex items-center justify-center`），和按钮右侧的内边距贴齐。

### 空间的松和紧

- **大留白：** 把你平时用的区块内边距加倍。区块用 `py-24` 到 `py-40`。让版面喘得开。
- **眉题：** 大的 H1、H2 前面放一枚极小的胶囊徽章（`rounded-full px-3 py-1 text-[10px] uppercase tracking-[0.2em] font-medium`）。

## 动效要有质量

不要用默认的过渡。动作要像有重量、有弹簧。用自定义的三次贝塞尔，例如 `transition-all duration-700 ease-[cubic-bezier(0.32,0.72,0,1)]`。

### 浮动胶囊导航，和汉堡图标展开

- **收起：** 导航是脱离顶边的浮动玻璃胶囊（`mt-6`、`mx-auto`、`w-max`、`rounded-full`）。
- **汉堡变成叉：** 点击后，两或三条线要转、要平移，合成一个叉（绝对定位下的 `rotate-45` 和 `-rotate-45`），不是直接消失。
- **菜单展开：** 菜单是铺满屏幕的遮罩，玻璃很重（`backdrop-blur-3xl bg-black/80` 或 `bg-white/80`）。
- **错峰露出：** 展开后的链接不是一下子出现。它们从一个看不见的盒子里淡入并上移（从 `translate-y-12 opacity-0` 到 `translate-y-0 opacity-100`），每一项延迟错开（`delay-100`、`delay-150`、`delay-200`）。

### 按钮悬停像有磁力

- 用 `group`。悬停时不要只改背景色。
- 整颗按钮按下时略缩小（`active:scale-[0.98]`），像真的被按下去。
- 里面那个小圆图标沿对角线挪一点（`group-hover:translate-x-1 group-hover:-translate-y-[1px]`），并略放大（`scale-105`）。

### 滚进视口时才出现

- 元素不要在加载时就静静待在那里。进入视口时，做一次慢的、有重量的上浮（从 `translate-y-16 blur-md opacity-0` 到 `translate-y-0 blur-0 opacity-100`，800ms 以上）。
- 用 JavaScript 做滚动揭示时，用 `IntersectionObserver`，或 Framer Motion 的 `whileInView`。不要用 `window.addEventListener('scroll')`，它会不停触发布局，手机上会卡。

## 性能

- **只动合成器友好的属性：** 不要对 `top`、`left`、`width`、`height` 做动画。只动 `transform` 和 `opacity`。`will-change: transform` 少用，只加在正在动的元素上。
- **模糊的限制：** `backdrop-blur` 只加在固定或吸顶的元素上（导航、遮罩）。不要加在滚动容器或大块内容上，否则 GPU 会一直重画，手机掉帧。
- **噪点层：** 噪点只放在固定的、不接收指针的伪元素上（`position: fixed; inset: 0; z-index: 50`）。不要挂在滚动容器上。
- **层叠：** 不要随便写 `z-50` 或 `z-[9999]`。层叠只留给固定的几层：吸顶导航、对话框、遮罩、提示。

## 做的顺序

1. 先按上一节选定气质和版式。不要写进给用户看的说明里，直接选。
2. 定背景质感、大留白的尺度，以及很大的字号。
3. 主要卡片、输入框、功能格子都用双层边框。圆角用夸张的超椭圆（`rounded-[2rem]`）。
4. 加上自定义的 `cubic-bezier` 过渡、错峰的导航揭示，以及按钮里套按钮的悬停。
5. 交出能用的 React、Tailwind 或 HTML。不要附一套普通的、通用的退路。

- 主要卡片和容器都是外壳加内芯
- 该用的主按钮，尾部图标套在自己的圆里
- 区块内边距至少 `py-24`
- 过渡都是自定义三次贝塞尔，没有 `linear` 或 `ease-in-out`
