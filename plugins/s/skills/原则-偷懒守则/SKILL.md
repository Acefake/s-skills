# 偷懒守则

- **把决定合并到一处。** 不要在好几个地方重复同一个选择。把它放在唯一的事实来源后面，再把结果当作一个简单的开关传下去。
- **让 diff 尽量小。** 做能解决问题的最小改动。行数少，胜过“优雅”的样板代码。
