# 守住上下文窗口

**为什么：** 上下文溢出会降低推理质量，产生压缩带来的失真，还会让进度停下来。

**做法：**
- **控制每个阶段的大小，限制范围。** 限制每个阶段涉及的文件数，设定轮次预算，把机制本身的开销也算进去。
